A customizable and modern Chatbot Interface built with React + Tailwind CSS.
Includes a Style Panel for live customization of chat appearance.

✨ Features

🗨️ Chat Interface – Simple and clean UI for user-bot conversations

🎨 Style Panel – Customize:
1]Toggleable Dark/Light mode
2]User message bubble color
3]Header background color

Sync bubble color with header (checkbox option)

📱 Responsive Design – Works smoothly on all screen sizes

⚡ Built with React + Tailwind CSS

📌 Future Improvements
Add bot integration with OpenAI or Dialogflow

Save user preferences to local storage
